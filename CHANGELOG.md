# Changelog

## [1.0.0]

Initial release of Launchpod for macOS 26 and later.

- Browse and launch apps in Classical mode, with pages, folders, search, and drag-and-drop organization.
- Open Launchpod from the Dock, menu bar, or a global keyboard shortcut.
- Customize appearance, app directories, and the icon grid in native macOS settings.
- Use the app in English, Simplified Chinese, Traditional Chinese, French, German, Japanese, Korean, or Spanish.
- Receive automatic update prompts, or check manually from the menu bar. A red indicator appears when an update is available.
- Download the latest signed and notarized Universal Mac installer from GitHub Releases.
